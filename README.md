# 人物描寫分類互動白板

適合國小國語文課堂、電子白板與平板操作的單頁互動教材。

## 教學關卡

1. **依人物分類**：美如奶奶、我的好朋友、媽媽的變化。
2. **依寫作類別分類**：外型描寫、興趣／事件／行為、情感與期望。

## 操作方式

- 使用滑鼠或觸控拖曳牌卡。
- 也可先點選牌卡，再選擇分類區。
- 可顯示或隱藏參考答案，並一鍵重新分類。
- 網頁無外部套件，可下載 `index.html` 離線使用。
